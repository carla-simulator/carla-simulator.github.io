float  Cx,

)

Explicit intrinsics in normalized viewport units, the same convention as sensor.camera.rt_lens: x_px = (Cx + Fx * R * cos(phi)) * Width, y_px = (Cy + Fy * R * sin(phi)) * Height.

Fx <= 0 disables the override and the projection falls back to the fov / focal_length attributes with the principal point at the image centre.
