19/// A path-traced camera sensor ("sensor.camera.rt_lens") that renders through
20/// a configurable lens model (see Util/CameraModelUtil.h for the model
21/// contract) instead of the stock linear pinhole projection.
22///
23/// Unlike ASceneCaptureCamera_WideAngleLens, the lens distortion here is not
24/// a 2D post-process warp applied to a rasterized cubemap: the lens model is
25/// evaluated per-ray inside the path tracer itself, via genuine per-view
26/// FPostProcessSettings fields (see RTLensEngineAdapter.h), so multiple
27/// simultaneous rt_lens cameras with different lens models do not interfere
28/// with each other. Consequently this sensor captures through a single
29/// USceneCaptureComponent2D, exactly like ASceneCaptureCamera, and reuses the
30/// same standard RGB readback path instead of the WideAngleLens family's
31/// 6-face cubemap + compute-shader resample pipeline.

69 /// Runs this tick's capture and this tick's readback in the order the world's
70 /// synchronization mode requires, then returns. Every path-traced lens sensor
71 /// must go through here so colour and AOV cameras stay on the same frame.
72 ///
73 /// EnqueueReadback is invoked at most once, only when clients are listening,
74 /// with the bNonBlocking flag to hand to the ImageUtil::ReadImageData*
75 /// overload; the callee just issues its own read of GetCaptureRenderTarget().
76 ///
77 /// Synchronous mode: capture first, then a BLOCKING readback of what was just
78 /// rendered, delivered by FSensorManager's single per-tick
79 /// ImageUtil::FlushBatchedReadbacks() GPU sync -- the frame the client gets
80 /// for tick k is tick k's render and cannot be dropped.
81 /// Asynchronous mode: readback first (of the previous tick's pixels), then
82 /// capture, never waiting on the render thread -- one tick of latency and
83 /// frames may drop under load, but the server cannot stall.
84 ///
85 /// Context is the capture metadata matching the pixels this readback will
86 /// pull: this tick's in synchronous mode, the PREVIOUS tick's in async mode.

88 UWorld *World,
89 ELevelTick TickType,
