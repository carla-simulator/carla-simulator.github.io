Detailed Description

Subsystem responsible for simulating all ray-cast LiDARs of a world.

Registered LiDARs are simulated asynchronously via TaskGraph high-priority worker tasks while the Game Thread processes remaining sensors (cameras, etc.). FSensorManager::PostPhysTick calls StartLidarSimulations() at the beginning of the post-physics tick, and FinishLidarSimulations() after other sensors finish.
