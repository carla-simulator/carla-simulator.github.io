uint64_t carla::rpc::Actor::spawn_frame = 0u

Server frame counter when a spawn call created this actor: snapshots up to and including this frame predate it.

0 when the actor did not come from a spawn call, or from a server that does not report it. Last in the array so that either side reads the other's older layout.
