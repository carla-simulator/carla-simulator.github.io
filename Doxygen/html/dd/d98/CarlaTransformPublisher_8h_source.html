23// Publishes tf2_msgs::msg::TFMessage to the global "rt/tf" topic. Each
24// sensor owns its own instance and contributes one TransformStamped per
25// tick; subscribers see the full set fanned out across the topic. Callers
26// hand in raw float translation + Euler degrees so the header does not
27// include carla::geom::Transform (pulls MsgPack + Boost via
28// carla/MsgPack.h — neither is on the include path of the
