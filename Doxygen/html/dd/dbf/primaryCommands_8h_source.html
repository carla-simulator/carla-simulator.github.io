68 /// Routes every sensor whose secondary disconnected to the secondaries
69 /// connected since the previous call, under the same primary stream id,
70 /// so clients already subscribed reconnect to it without a new listen().
71 /// The first new secondary that stays connected takes every lost sensor.
72 /// A sensor the new secondary refuses is forgotten and routed lazily
73 /// later; if it disconnects instead, the sensor stays lost for the next
74 /// one. ROS publishing enabled through EnableForROS() is enabled again.
75 /// Blocks on round trips; never call it from a Router callback. Returns
76 /// how many sensors were routed again.
77 std::size_t RerouteLostSensors();
