Detailed Description

Oriented box that stamps a nav area class onto the navmesh polys it overlaps (crosswalks generated from the OpenDRIVE by the CarlaCrosswalkNav world-partition builder).

The box body only provides the modifier bounds: it collides with nothing and is itself navigation-irrelevant (no Pawn or Vehicle block response), so it never rasterizes geometry into the navmesh.
