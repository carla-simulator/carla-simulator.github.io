Detailed Description

This is a simple wrapper class on Carla's waypoint object.

The class is used to represent discrete samples of the world map.

void carla::traffic_manager::SimpleWaypoint::ClearLinks ( )

Drops the links to the neighbouring waypoints (next, previous, left and right).

They are shared pointers that point at each other, so a graph of waypoints is freed only once they are dropped.
