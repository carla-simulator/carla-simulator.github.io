Detailed Description

Mounts CARLA content packs (content-only Unreal plugins cooked as DLC against a base release, wrapped with a carla-pack.json manifest) into the running process, editor or cooked game alike.

Implemented as a UEngineSubsystem: it outlives game instances and worlds, so packs survive load_world, and it exists before the first map loads. Auto-discovery runs from Initialize() in game processes (packaged binary or editor -game); FCarlaEngine::NotifyInitGame calls Discover() again as a no-op safety net so the RPC server never starts before the packs are in. The full editor and commandlets (the cooker) do not auto-mount packs.
