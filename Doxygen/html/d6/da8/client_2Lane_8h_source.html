25 /// A single OpenDRIVE lane, identified by (road id, lane section id, lane id).
26 ///
27 /// A lane lives inside exactly one lane section, which is why its identity
28 /// carries the section: the same lane id on the same road is a different lane
29 /// in a different section. Following GetNextLanes() can therefore cross into
30 /// another section, or return nothing where the lane simply ends.
31 ///
32 /// Like carla::client::Junction, this holds the parent map alive and resolves
33 /// its ids on each call rather than caching a road::Lane pointer, which would
34 /// dangle once the map is released.
