std::vector< uint32_t > carla::multigpu::OrderParentsFirst ( const std::vector< uint32_t > & ids,
const std::unordered_map< uint32_t, uint32_t > & parents )
inline

Order in which to place actors so that every parent is placed before its children: by attachment depth, keeping the input order within a depth.

parents maps an id to its parent's id (absent or 0 for a root). A parent that is not among ids counts as a root, and so does every actor of a cycle, so the result always holds every id once.
