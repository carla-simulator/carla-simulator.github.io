15/// Environment-map support for the sky light (the `set_sky_light_map` RPC).
16///
17/// Convention of the input panorama (equirectangular, CARLA world frame,
18/// which is Unreal's left-handed X forward / Y right / Z up):
19/// column u in [0, W): azimuth phi = 2*pi * (u + 0.5) / W, measured from +X
20/// toward +Y (the same sense as a CARLA yaw: 0 = +X, 90 deg = +Y).
21/// row v in [0, H): elevation theta = pi/2 - pi * (v + 0.5) / H
22/// (row 0 = zenith, last row = nadir).
23/// direction d = (cos(theta) cos(phi), cos(theta) sin(phi), sin(theta)).
24/// Pixels are linear RGBA float, row-major, top row first. Values are scene
25/// radiance in whatever unit the caller wants; the sky light's Intensity is
26/// the multiplier on top.
27namespace CarlaSkyLightMap

29 /// Resamples the panorama into a transient 6-face HDR cubemap

33 /// world direction returns the panorama value for that direction.
34 /// Returns nullptr on bad input. The texture is NOT rooted: the caller owns
