Detailed Description

A fixed-sweep ray-cast Lidar approximating a Hybrid Solid-State LiDAR (e.g.

Hesai AT128). Unlike ARayCastLidar this sensor does not rotate; each tick it casts a configurable horizontal field of view at a fixed angular resolution centred on the sensor's forward axis.
