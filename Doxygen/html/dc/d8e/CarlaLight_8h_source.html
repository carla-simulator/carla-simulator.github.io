118 // Registers with UCarlaLightSubsystem so it can preview day/night toggling
119 // in the editor too, not just once actually playing -- BeginPlay (the only
120 // other place that calls RegisterLight) never fires outside Play/PIE, so
121 // in a pure editor world nothing was ever registered and the day/night
122 // broadcast had zero listeners. RegisterLight() is idempotent (checks its
123 // own Registered flag), so this is harmless alongside BeginPlay's call.

130 // old Id in the subsystem's map (RegisterLight's collision-avoidance loop

246 /// Show or hide every Point/Spot/Rect light component on the owner. The
247 /// blueprint UpdateLights event is supposed to react to state changes, but
248 /// several ported lamp blueprints have dead UpdateLights graphs, which left
249 /// the client light API (turn_on/turn_off/set_light_state) without any
250 /// visual effect. Enforce the on/off state from C++ so the API works
251 /// regardless of the content blueprint.

254 /// Sets the Intensity of every Point/Spot/Rect light component on the owner

257 /// the native component (confirmed by instrumented testing -- logged
258 /// component intensity was identical before and after UpdateLights() in
259 /// every case, at registration and on a live Reapply), so intensity needs
260 /// the same native enforcement on/off already has.

267 /// Pushes the "EmissiveIntensity" scalar (and the "On/Off" gate scalar) of
268 /// every StaticMeshComponent's materials on the owner, via a per-instance
269 /// MID. The lamp materials (M_Artificial_Lamp / M_MaterialMaster and their
270 /// instances, e.g. M_StreetLight06) author "On/Off" defaulting to 0, which
271 /// forces their emissive Lerp to black regardless of EmissiveIntensity --
272 /// confirmed the reason editing emissiveIntensity from the Light Defaults
273 /// tool never visibly did anything: nothing ever flipped that gate. Setting
274 /// On/Off alongside EmissiveIntensity here (on whenever Value > 0) fixes
275 /// that without touching the ported material graph. No-ops safely on
276 /// materials without these parameters (e.g. the glass lens materials).
277 void ApplyEmissiveToComponents(float Value);
278
279 /// Applies Value to the material immediately and once more a tick later
280 /// (see the comment in SetEmissiveIntensity's .cpp body) WITHOUT touching
281 /// the EmissiveIntensity member -- the day/night handler uses this to
282 /// visually turn the glow off by day and back on by night while keeping
283 /// the authored/saved intensity intact for the next real edit.

286 /// The pending "next tick" retry's handle -- a NEW call reuses/cancels it

288 /// of calls landing in the same or adjacent tick (e.g. dragging
289 /// SunAltitudeAngle: each edit re-broadcasts day/night to every light)
290 /// left multiple stale timers in flight, each capturing its OWN Value from
