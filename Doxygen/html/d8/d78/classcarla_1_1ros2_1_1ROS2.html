bool carla::ros2::ROS2::Enable ( bool  enable,
Middleware  middleware = Middleware::FastDDS,
int  domain_id = kUnsetDomainId 
)

Enable or disable ROS 2 publishing.

When enabling, middleware selects the DDS middleware; it must have been compiled into the shared library. domain_id selects the ROS 2 domain id for the chosen middleware; kUnsetDomainId (the default) keeps each middleware's native default.

Returns
true on success, false if the requested middleware is unavailable (ROS 2 is then left disabled).
