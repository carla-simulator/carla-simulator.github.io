Detailed Description

Secondary-side map from a primary sensor actor to its local stream, exposed to clients only through an alias of the primary's stream id.

Entries are per primary episode. Resolve() and BeginEpisodeChange() run on the multi-GPU command thread, the rest on the game thread.
