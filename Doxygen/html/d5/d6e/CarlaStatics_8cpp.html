static TArray< FAssetData > UCarlaStatics_GetRegistryWorlds ( )
static

UWorld assets the asset registry knows outside /Engine (project content, mounted plugins, content packs).

Cooked base maps live inside Pak/IoStore containers where the .umap walk finds nothing; the premade AssetRegistry.bin of a packaged build still lists them. The registry asserts on non-game threads, so off-thread callers get an empty list.
