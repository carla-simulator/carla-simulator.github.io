Detailed Description

Thin wrapper over the engine navigation system (UNavigationSystemV1) used by the server-side pedestrian navigation RPCs.

On World Partition maps the navmesh streams with the cells, so every query below operates on the currently loaded tiles only.

bool UCarlaNavigationSubsystem::GetRandomNavLocation ( FVector & OutLocation) const

Random point on the loaded navmesh where a walker can stand, in world-local centimeters.

Points whose surroundings are still streaming in, or where a walker capsule would overlap static geometry (the terrain under a building footprint, issue #10212), are resampled; returns false when no acceptable point is found.
