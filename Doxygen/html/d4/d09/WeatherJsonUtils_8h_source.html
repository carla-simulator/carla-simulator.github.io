124 // MapName's entry, resolved regardless of which of the two shapes
125 // MapDefaults.json holds it in:
126 // { "Town10HD_Opt": { "time": "Noon", "condition": "Clear" } } -- named presets, merged onto Base
127 // { "Town10HD_Opt": { "sunAzimuthAngle": 180, "cloudiness": 5, ... } } -- a full inline snapshot
128 // A map's hand-tuned one-off setup doesn't need a named preset invented
