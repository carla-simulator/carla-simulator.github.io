12 /// Sensor type ids as the ROS 2 interface sees them.
13 ///
14 /// Cameras reach ROS2::ProcessDataFromCamera with the sensor type from their
15 /// data header, which is the sensor's position in carla::sensor::SensorRegistry.
16 /// Each value here must therefore be that position: one entry per registry
17 /// item, in the same order, including sensors that ROS 2 does not publish.
18 /// SensorFactory.cpp checks every entry against the registry at compile time,
19 /// so a sensor added to the registry without a matching entry here fails the
20 /// build instead of silently shifting every camera after it.
