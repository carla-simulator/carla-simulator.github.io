28// Names and actor-relative transforms of an actor's scene components, bones and
29// authored sockets, so a dormant actor answers the same queries as a live one.

39 // Reads the rig off a live actor. Every transform is relative to the actor,
40 // so composing it with the actor transform gives world space either way.
41 static FActorRigSnapshot FromActor(const AActor *Actor);
42};
