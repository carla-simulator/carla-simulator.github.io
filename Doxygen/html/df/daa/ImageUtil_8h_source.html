136 // Pool-aware variant: when Pool is non-null, the per-call FRHIGPUTextureReadback
137 // alloc is recycled through the per-sensor pool.
138 //
139 // bNonBlocking (default false = original behaviour for every existing caller):
140 // when true the render thread only records the copy and returns; completion is
141 // polled off-thread. Used by the path-traced rt_lens sensor, whose readback
142 // must never wait on the GPU on the render thread -- that wait deadlocks the
143 // server under load (see ImageUtil.cpp).
144 //
145 // Blocking (default) calls do NOT deliver on their own anymore: they record
146 // the copy and join the current tick's batch, which is synchronized and
147 // delivered by FlushBatchedReadbacks() (called once per tick by
148 // FSensorManager after every sensor has enqueued its capture).
149 bool ReadImageDataAsync(
150 UTextureRenderTarget2D& RenderTarget,
151 FRHIGPUReadbackPoolPtr Pool,
152 ReadImageDataAsyncCallback&& Callback,
153 bool bNonBlocking = false
154 );
