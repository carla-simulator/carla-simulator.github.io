std::optional< token_type > carla::multigpu::PrimaryCommands::GetToken ( stream_id  sensor_id,

Returns std::nullopt if no secondary could provide the token (e.g.

the selected secondary disconnected with the request in flight, or has no episode loaded). Nothing is cached on failure, so a later call for the same sensor retries. A sensor whose secondary disconnected is routed again here. sensor_actor_id is the primary's id of the sensor actor, which the secondary resolves to its own sensor stream.

◆ RerouteLostSensors()

std::size_t carla::multigpu::PrimaryCommands::RerouteLostSensors ( )

Routes every sensor whose secondary disconnected to the secondaries connected since the previous call, under the same primary stream id, so clients already subscribed reconnect to it without a new listen().

The first new secondary that stays connected takes every lost sensor. A sensor the new secondary refuses is forgotten and routed lazily later; if it disconnects instead, the sensor stays lost for the next one. ROS publishing enabled through EnableForROS() is enabled again. Blocks on round trips; never call it from a Router callback. Returns how many sensors were routed again.
