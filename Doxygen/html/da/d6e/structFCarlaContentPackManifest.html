Detailed Description

Parsed carla-pack.json.

Authoritative for map discovery: nothing walks the pack directories looking for .umap files.

{ "name": "NewPack", "version": "1.0.0", "carla_version": "0.10.2", "base_release": "carla-0.10.2-Linux", "engine": { "version": "5.8.0", "commit": "abcdef0" }, "platform": "Linux", "maps": [ { "name", "package", "xodr", "world_partition" } ], "catalogs": [ "Config/Vehicles.json", ... ], "files": { "<relpath>": "sha256:..." } }
