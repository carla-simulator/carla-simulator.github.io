81 // Global TF gate (tier4 port): when false, no sensor broadcasts its
82 // transform on /tf. Complements the per-sensor publish_tf flag set at
83 // RegisterSensor time; both must be true for a transform to go out.

88 // actor registration API: replaces the legacy AddActorRosName /
89 // GetActorRosName / GetActorParentRosName surface that PR-2 stubbed and
90 // PR-4 retired. The plugin calls RegisterSensor / RegisterVehicle when an
91 // actor spawns and Unregister* when it destroys; ROS2 builds the topic
92 // names, owns per-sensor publishers + TF, and routes subscriber
93 // callbacks. The vehicle gets exactly one control subscriber: the Ackermann
94 // subscriber when enable_ackermann_control is true, otherwise the direct
95 // VehicleControl one. The two control topics are mutually exclusive so they
96 // cannot contend frame to frame.
97 void RegisterSensor(
98 void *actor, std::string ros_name, std::string frame_id, bool publish_tf);
99 void UnregisterSensor(void *actor);
100 // The vehicle gets exactly one control subscriber. enable_autoware_control
101 // wins over enable_ackermann_control (tier4 gave the Autoware command path
102 // priority); it wires the six /control/command/* + /vehicle/engage
103 // subscribers and marks the vehicle as the Autoware ego so
104 // ProcessDataFromStatusSensor accepts its status stream. Default behavior
105 // (both flags false) is unchanged for non-Autoware users.
106 void RegisterVehicle(
107 void *actor, std::string ros_name, std::string frame_id, ActorCallback callback,
108 bool enable_ackermann_control = false,
109 bool enable_autoware_control = false);
110 void UnregisterVehicle(void *actor);
111
112 // Exact-topic-name override (tier4 port of the ros_topic_name attribute
113 // flow). When set (non-empty), the actor's publishers/subscribers bind to
114 // "rt[/]<ros_topic_name>" instead of the "rt/carla/[parent/]ros_name"
115 // convention; multi-topic sensors still append their per-topic suffixes.
116 // The UE side reads the blueprint's "ros_topic_name" attribute and calls
117 // AddActorRosTopicName before the first data tick (next phase); Remove also
118 // drops the actor's cached publishers so a re-registration rebinds cleanly.
119 void AddActorRosTopicName(void *actor, std::string ros_topic_name);
120 void RemoveActorRosTopicName(void *actor);
121 std::string GetActorRosTopicName(void *actor) const;

123 // Topic-hierarchy seam used by the plugin's attach_actor path: tells ROS2
