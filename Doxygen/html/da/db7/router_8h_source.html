131 /// Re-arms the new-connection resync if @a buffer is the secondary's
132 /// episode-ready marker (checked first, so it can never be misdelivered
133 /// to a pending promise on the same session); otherwise resolves the
134 /// pending promise for @a session with @a buffer, or logs and drops the
135 /// data if no request is currently pending on it.
136 void HandleResponse(std::shared_ptr<Primary> session, Buffer buffer);
137
138 /// Fails a pending request instead of leaving its future unresolved.
139 /// A session can vanish (dead weak_ptr, disconnect, empty router) between
140 /// the moment a promise is created and the moment a response would have
141 /// arrived; without this, the caller's std::future::get() blocks forever.
142 ///
143 /// The failure is delivered as a value (a SessionInfo with a null
144 /// session), never through std::promise::set_exception(): inside the
145 /// CarlaUnreal process std::rethrow_exception() binds to the libc++abi
146 /// copy exported by libcarla-ros2-native.so, while exceptions are
147 /// allocated and caught by libstdc++'s ABI. std::current_exception() then
148 /// sees a foreign exception and returns null, so the rpc sync-call
149 /// packaged_task becomes ready with neither a value nor an exception and
150 /// the rpc thread reads an unconstructed result (SIGSEGV).
151 static void RejectPromise(
152 std::shared_ptr<std::promise<SessionInfo>> promise,
153 std::string_view reason);
